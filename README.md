# Netflix Data Analysis 📊

## Overview
This project analyzes Netflix dataset using Python libraries such as:
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Features
- Movies vs TV Shows analysis
- Top countries analysis
- Ratings distribution
- Release year trends
- Data visualization using graphs

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
Netflix Titles Dataset from Kaggle

```
Netflix-Data-Analysis/

├── netflix_analysis.py

└── README.md
```

## Sample Insights
- Movies are more common than TV Shows
